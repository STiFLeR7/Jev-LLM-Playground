# Jev Playground
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Developers learning Jev and engineers inspecting reproducible decision experiments, using a local browser and CLI.

## Product Purpose
Define a support-routing or agent-routing question, inspect typed answers, apply an application-owned policy, and explore saved evidence.

## Capabilities and Constraints
Dependency-free Node and native browser application. Preview is keyless; live calls require explicit opt-in and server-side credentials. Recorded evidence is read-only. Agent Lab permits one consented pure local calculation, word count, or checklist transformation; browser routing modes are offline, with an explicit NVIDIA text-generation opt-in. Live agent routing uses the budgeted CLI. The NVIDIA handoff is text-only and never executes generated instructions. No training, deployment, arbitrary tool execution, billing plan, or generic chat capability is offered.

## Brand Commitments
User-approved Decision Studio direction (2026-09-22), based on their supplied three-panel product UI reference. Playground, Evidence, Learn, Agent Lab navigation; compact controls and result canvas. Calm, precise, developer-focused language. Independent community project, not official TypeSafe software.

## Evidence on Hand
Historical 16-case report, v2 and v3 48-case repeated benchmarks, original synthetic inputs, and blind AI reference review. No production reliability claim or independent human adjudication.

## Product Principles
- Separate model answers from application policy.
- Keep preview, live, and recorded states explicit.
- Preserve saved evidence and meaningful denominators.
- Support keyboard use and responsive layouts.
