        The model answers. You set the policy.
        The playground validates the response, then checks the category and confidence. “Other” and below-threshold answers go to human review. Everything else gets a suggested team.
        A confidence value is not a correctness guarantee. The application trace explains these steps, not hidden model reasoning.
