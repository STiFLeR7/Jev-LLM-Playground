# v0.2.0 — Reproducible Decision Bench

This release adds a frozen, repeated support-routing benchmark and a durable local API spending guard. The v0.1.0 browser experience and historical evidence remain unchanged.

## What's new

- 48 synthetic test cases and 8 development examples covering clear requests, negation, mixed intent, and embedded routing instructions.
- Three-pass evaluation with classification metrics, wrong automatic routes, review precision/recall, confidence bins, fixed threshold sensitivity, and repeated-decision agreement.
- Durable integer-based spending reservations, shared local ledger/lock, checkpointed observations, fail-closed errors, and no automatic retries.
- Offline replay validates configuration, observations, routing decisions, pricing, budget arithmetic, reservations, and stop states.
- Curated pre-run snapshot, all 144 live observations, budget audit journal, methodology, and engineering write-up.
- 33 automated tests and keyless benchmark/replay CI checks. No runtime dependencies added.

## Recorded results—not general performance claims

Jev matched the author-assigned labels on 48/48 unique synthetic cases in each of three passes (144/144 observations). The unchanged keyword baseline matched 28/48. At threshold 0.8 there were 108 suggested routes, 36 reviews, and zero incorrect automatic routes.

Reported usage was 76,146 input tokens: **USD 0.003198132 estimated cost against a USD 0.05 cap**. All reservations and settlements reconcile. This is pricing-based accounting, not a provider invoice or account-wide spending control.

The repetitions are correlated, labels are not independently adjudicated, and no confidence fell below 0.8. Categories/routes stayed consistent, but full answers varied for 40/48 cases. These observations do not establish general accuracy, calibration, determinism, prompt-injection immunity, or production reliability.

## Try it without an API key

Requires Node.js 22.9 or newer:

```sh
git clone --branch v0.2.0 https://github.com/STiFLeR7/Jev-LLM-Playground.git
cd Jev-LLM-Playground
npm test
node benchmark.mjs --config data/support-routing-v2.json
node benchmark.mjs --replay doc/results/benchmark-v2-live-2026-09-21.json
```

These commands make zero provider calls. Paid runs require explicit authorization, budget and output arguments; see the protocol. The browser still displays the historical 16-case experiment, not this new benchmark.
