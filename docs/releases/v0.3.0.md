# v0.3.0 — Challenge Bench and Confidence Gating

This release adds 48 harder synthetic support-routing cases, eight development examples, blind review by a separate AI reviewer, and separate metrics for agreed and disputed references. No runtime dependencies or new provider calls were added during release preparation.

## Evidence

- One frozen experiment: 144 observations across three correlated passes; no API errors or retries.
- Agreed references: 121/126 matching attempts across 42 cases (96.03%). Keyword baseline: 14/42 cases (33.33%).
- All author references: 124/144 matching attempts (86.11%); six disputed cases remain explicitly separated.
- At the frozen 0.8 threshold: 75 automatic routes, 69 reviews, zero observed wrong automatic routes. All five agreed-reference mismatches were reviewed, alongside 15 correctly classified in-scope attempts.
- Estimated new cost: USD 0.003221568; cumulative v2/v3 ledger cost: USD 0.006419700 under the approved USD 0.05 cap. This is usage-based estimation, not a provider invoice or account-wide cap.
- 37 automated tests, retained pre-run snapshot, live observations, cumulative spending journal, and offline replay checks.

Blind AI review is not independent human adjudication. Synthetic cases and repeated observations do not establish general accuracy, calibration, or production reliability. The browser still displays the historical 16-case report; v3 evidence is available through the CLI and documentation. Original evidence and earlier tags are preserved.

## Try it offline

```sh
git clone --branch v0.3.0 https://github.com/STiFLeR7/Jev-LLM-Playground.git
cd Jev-LLM-Playground
npm test
node benchmark.mjs --config data/support-routing-v3.json
node benchmark.mjs --replay doc/results/benchmark-v3-live-2026-09-21.json
```

Requires Node.js 22.9 or newer. These commands make no provider calls. MIT license unchanged.
