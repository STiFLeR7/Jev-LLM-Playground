# v0.1.0 — Decision Trace & Evidence Explorer

First tagged release of Jev LLM Playground: an independent, MIT-licensed learning and evaluation project for TypeSafe AI's Jev decision model.

## Highlights

- **Application decision trace:** follow submitted input, shared questions, validation, routing policy, and suggested action. Preview stages stay pending; the trace is not hidden model reasoning.
- **Recorded evidence explorer:** inspect the saved 16-ticket experiment locally, including model/baseline confusion matrices, explicit denominators, provenance warnings, and case filters.
- **Safer decision boundaries:** normalized responses, threshold-driven human-review suggestions, sanitized failures, timeouts, and a fixed read-only report endpoint.
- **Reproducible experiments:** versioned evaluation config, dataset/config/source hashes for new runs, keyword baseline, and offline replay.
- **Learning material:** Jev 101, architecture, support-routing recipe, evaluation guidance, contribution templates, and labeled desktop/mobile screenshots.
- **MIT license** for original project code/documentation and GitHub private vulnerability reporting.

## Try it

Requires Node.js 22.9 or newer. No runtime dependencies.

```sh
git clone --branch v0.1.0 https://github.com/STiFLeR7/Jev-LLM-Playground.git
cd Jev-LLM-Playground
npm test
npm start
```

Open http://127.0.0.1:3000. Preview a synthetic ticket or select **Load recorded experiment**. Neither requires an API key or makes a provider call. Live mode is explicit, sends ticket text to TypeSafe, and consumes API credits.

## Evidence and operational limits

The saved synthetic experiment recorded 16/16 correct department labels for Jev and 12/16 for the keyword baseline. This does **not** establish general accuracy, calibration, or production reliability. Legacy provenance is incomplete; urgency and frustration are unlabeled, and repeat consistency is unproven.

No new paid API runs were made for this release. The application only suggests routes; it does not move tickets, issue refunds, or run tools. It is loopback-only, not a hosted service. Keyboard/responsive checks are not a full accessibility audit.

TypeSafe's model, API, branding, and referenced third-party materials retain their own terms; this project is not officially affiliated with TypeSafe. MIT provides no warranty.

Report security concerns privately through [GitHub vulnerability reporting](https://github.com/STiFLeR7/Jev-LLM-Playground/security/advisories/new).
